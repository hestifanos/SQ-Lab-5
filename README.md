# Software Quality Lab 5: Data Expectations

A Jupyter notebook exercise exploring data validation and expectations with the Great Expectations workflow.

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab
- pandas
- Great Expectations

Install the dependencies before opening the notebook:

```bash
python -m pip install jupyter pandas great-expectations
jupyter notebook
```

The notebook loads the UCI Adult dataset from the internet, so an active network connection is required. Run the cells from top to bottom in a clean Python environment.
